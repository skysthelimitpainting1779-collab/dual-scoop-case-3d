# Dual Scoop Case – Print Ready

3D-printable dual-scoop clamshell case based on the physical object photos.

## Files

| File | Description |
|------|-------------|
| `dual_scoop_v3.scad` | Full parametric OpenSCAD source |
| `PRINT_scoop.stl` | Removable scoop (print **2**) |
| `PRINT_full_open_case.stl` | Full case opened flat with living hinge (recommended) |
| `dual_scoop_full.glb` | GLB for 3D viewing |

## Print Settings (Dremel / FDM)

- **Material**: PETG preferred (better living hinge). PLA works but stiffer.
- **Layer height**: 0.16–0.2 mm
- **Walls**: 3–4 perimeters
- **Infill**: 15–25%
- **Supports**: None needed
- **Orientation**: Full open case flat on bed; scoops tray-side down

## Dimensions

- Overall length ≈ 100 mm
- Closed width ≈ 42 mm
- Closed height ≈ 17 mm
- Scoop bowls Ø 18 mm

## How to modify

Open `dual_scoop_v3.scad` in OpenSCAD, tweak the parameters at the top, then re-export the parts you need.
